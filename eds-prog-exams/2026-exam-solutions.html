Block 2: Fixed point iteration

In this question you will use an iterative algorithm to find a fixed point of a function up to a tolerance level \epsilon_{tol}. A fixed point of a function f is a value x^\star that satisfies x^\star=f(x^\star).

The steps of the algorithm are as follows:

  1. Begin with the initial guess x_0 for x^\star.
  2. Update the guess to x_1 according to f(x_0).
  3. If |x_1-x_0|\leq \epsilon_{tol}, return x_1. Otherwise set x_0=x_1 and return to step 2.

You will write a Python function that takes three inputs:

  1. f, the function we want to find a fixed point of.
  2. x0, the initial guess for the fixed point of f.
  3. tol, the numeric value of the tolerance level \epsilon_{tol}.
  1. Define a Python function called f1 in the box below that computes f_1(x)=\frac{1}{1+x} given input x.

Answer:

def f1(x):
    return 1 / (1 + x)
  1. Define a Python function called f2 in the box below that computes f_2(x)=e^{-x} given input x.

Answer:

import math

def f2(x):
    return math.exp(-x)
  1. Define a Python function called fixedpoint that takes 3 arguments: f, x0, tol. This function should follow the algorithm in the block introduction and return the fixed point of the function f.

Answer:

def fixedpoint(f, x0, tol):
    dist = tol + 1
    while dist > tol:
        x1 = f(x0)
        dist = abs(x1 - x0)
        x0 = x1
    return x1
  1. Use the function fixedpoint with an initial guess x_0=1 and a tolerance \epsilon_{tol}=1\times 10^{-9} (use 1e-9 for \epsilon_{tol} in your code). Report the fixed points of functions f_1 and f_2.

Answer: The fixed point of f_1:

fixedpoint(f1, 1, 1e-9)
0.618033988957902

The fixed point of f_2:

fixedpoint(f2, 1, 1e-9)
0.5671432901223239

Block 5

You are a company that rents bicycles to visitors to a national park. You rent one type of standard bicycle and charge €5 per hour. Standard bicycle rentals have no additional fee. You also rent electric bicycles for €8 per hour and charge a fixed battery service charge of €12.

  1. Create a class called Rental. The class should include the following:
  • Have an __init__ method that takes the following two parameters and stores them as attributes:
    1. customer_name
    2. hours
  • Have a method called calculate_total() that returns the value of the rental in euros. This should be hours multiplied by 5.

Test your class using the following code, which should return 30:

test_rental_1 = Rental('Mathieu van der Poel', 6)
test_rental_1.calculate_total()

Answer:

class Rental:

    def __init__(self, customer_name, hours):
        self.customer_name = customer_name
        self.hours = hours

    def calculate_total(self):
        return self.hours * 5

Using the test code:

test_rental_1 = Rental('Mathieu van der Poel', 6)
test_rental_1.calculate_total()
30
  1. Create a second class called ElectricRental that inherits from the Rental class. The ElectricRental class should include the following:
  • Have an __init__ method that takes the same 2 arguments as Rental but has the following 3 attributes:
    1. customer_name
    2. hours
    3. battery_charge (set equal to 12).
  • Use super() to call the constructor of the Rental class and set the first 2 attributes.
  • Override the calculate_total() method so that it returns hours multiplied by 8 plus the battery service charge.

Test your class using the following code, which should return 52:

test_rental_2 = ElectricRental('Tadej Pogacar', 5)
test_rental_2.calculate_total()

Answer:

class ElectricRental(Rental):

    def __init__(self, customer_name, hours):
        super().__init__(customer_name, hours)
        self.battery_charge = 12

    def calculate_total(self):
        return self.hours * 8 + self.battery_charge

Using the test code:

test_rental_2 = ElectricRental('Tadej Pogacar', 5)
test_rental_2.calculate_total()
52
