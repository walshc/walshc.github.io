Excel (3 points)

Question 1 (1 point)

Download the following Excel file:

sales-report-sept-2026.xlsx

The file contains the total number of units sold per day for a company’s 10 products in September. Using a pivot table, obtain the total units sold for each product over the whole month. What is the product ID of the product which sold the most units?

Answer: 3.

To do this, select the table of data, add a pivot table, select the variables product id and sales, put product id on the rows, and the values should, by default, be the sum of sales by product ID. You can then sort this table by the sum of sales to see which product had the most sales.

Question 5 (1 point)

Consider the following 2 vectors:

products <- c("Lamp", "Chair", "Shelf", "Desk")
featured_products <- c("Chair", "Desk", "Sofa")

Write an R command using the %in% operator that returns the elements of products that are contained in the vector featured_products. The code you provide in your answer does not need to include the two lines above.

The output of your command should be [1] "Chair" "Desk".

Answer:

products[products %in% featured_products]
[1] "Chair" "Desk"

Question 6 (1 point)

Define x as follows:

x <- c(-3, 0, 8, -1, 5)

Write an R command in the box below with two nested uses of the ifelse() function that takes x as input and returns as output a character vector with:

  • "positive" whenever x is greater than zero.
  • "negative" whenever x is less than zero.
  • "zero" whenever x equals zero.

The output of your command should be [1] "negative" "zero" "positive" "negative" "positive".

Answer:

ifelse(x > 0, "positive", ifelse(x < 0, "negative", "zero"))
[1] "negative" "zero"     "positive" "negative" "positive"

Data Cleaning and Analysis (9 points)

Download the following dataset: yield-curves.csv. The data contain information on US treasury yields at different maturities (durations of the bonds) from the 3rd of September in 2024, 2025, and 2026. The data were obtained from the Federal Reserve Bank of St. Louis FRED Interface.

The variable descriptions are as follows.

  • date: The date in month/day/year format.
  • term: The maturity/duration of the security. This is in months if the duration variable equals month(s) and is in years if the duration variable equals year(s).
  • duration: Either year(s) or month(s) and describes whether the term variable is measured in years or months.
  • yield: The annualized return on the security.

For example, the first observation in the data tells us that the yield on a 1-year bond on 3 September 2024 was 4.35%.

When reading the dataset into R, assign it to df.

df <- read.csv("yield-curves.csv")

Question 7 (1 point)

Write an R command in the box below that will convert the date variable to an R date.

Answer:

df$date <- as.Date(df$date, format = "%m/%d/%y")

Question 8 (1 point)

Write an R command in the box below that will create a new variable called maturity which is the maturity/duration of the security measured in months. For example:

  • If term is 1 and duration is month(s), then maturity should equal 1.
  • If term is 2 and duration is month(s), then maturity should equal 2.
  • If term is 1 and duration is year(s), then maturity should equal 12.
  • If term is 2 and duration is year(s), then maturity should equal 24.

Answer:

df$maturity <- ifelse(df$duration == "year(s)", df$term * 12, df$term)

Question 9 (1 point)

Write an R command in the box below that will keep only the variables date, maturity and yield, dropping the variables term and duration.

Your output should match the following dataset: yield-curves-cleaned.csv.

Answer:

df <- df[, c("date", "maturity", "yield")]

Optimization (3 points)

The following two questions involve the mathematical function defined over all real numbers x:

f(x) = 18 + 12x - 2x^2

Question 16 (1 point)

Plot the function between the x values -2 and +8. Select or enter the correct options in the boxes below that best describe the plot.

Part (a): The shape of the function is a straight line / flat / U-shaped / inverse U-shaped.

Part (b): When f(x) = 34, the corresponding values of x are \_\_\_ and \_\_\_ (the answers are whole numbers).

Part (c): At x=5, the function is downward-sloping / flat / upward-sloping / vertical.

Answer:

f <- function(x) {
  18 + 12 * x - 2*x^2
}
x <- seq(-2, 8, length.out = 200)
plot_df <- data.frame(x = x, y = f(x))
ggplot(plot_df, aes(x, y)) + geom_line()
  1. The shape of the function is inverse U-shaped.
  2. When f(x)=34, the corresponding values of x are 2 and 4.
  3. At x=5, the function is downward-sloping.
