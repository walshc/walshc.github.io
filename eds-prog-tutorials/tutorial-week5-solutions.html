Question 1

Note: This question is almost identical to a question from the 2024 exam.

Download the dataset sales-data-2024.csv. The dataset contains the price and daily sales of a particular product. It has columns (or variables) with the following names:

  • 'year': The year part of the date.
  • 'month': The month part of the date as a number (1=Jan, 2=Feb, …, 12=Dec).
  • 'day_of_month': The day part of the date.
  • 'day_of_week': The day of the week as an abbreviated string ('Mon', 'Tue', etc.).
  • 'price': The price of the product on that date.
  • 'sales': The total number of units sold of the product on that date.

Read these data into Python as df. Use it to answer the following questions:

import pandas as pd
df = pd.read_csv("sales-data-2024.csv")
  1. Write a Python command that computes the average number of units sold per day.

Answer:

df['sales'].mean()
np.float64(2558.5476190476193)
  1. Create a new column/variable in df called 'daily_revenue' which equals price multiplied by daily sales.

Answer:

df['daily_revenue'] = df['price'] * df['sales']
  1. Write a Python command that computes and prints the mean daily revenue in the dataset.

Answer:

df['daily_revenue'].mean()
np.float64(24952.985952380954)
  1. Write a Python command that computes and prints the total number of units sold in May 2024.

Answer:

df[(df['year'] == 2024) & (df['month'] == 5)]['sales'].sum()
np.int64(80049)
  1. Write a Python command that creates a column/variable called 'weekend' which is True if 'day_of_week' is 'Sat' or 'Sun' and False otherwise.

Answer:

All the following commands would work:

df['weekend'] = [i in ['Sat', 'Sun'] for i in df['day_of_week']]
df['weekend'] = [i == 'Sat' or i == 'Sun' for i in df['day_of_week']]
df['weekend'] = (df['day_of_week'] == 'Sat') | (df['day_of_week'] == 'Sun')
df['weekend'] = df['day_of_week'].isin(['Sat', 'Sun'])
  1. Use the column/variable 'weekend' from part (e) to compute and print the average daily sales on days that are not on the weekend.

Answer:

df[~df['weekend']]['sales'].mean()
np.float64(2281.5333333333333)

Question 2

Download the dataset toyota-camry-ads.csv. This dataset contains information on classified advertisements placed on Craigslist for used Toyota Camry cars, one of the most common sedan cars in the US. The variables are:

  • condition: what kind of condition the car is in (good, like new, etc).
  • odometer: how many miles the car has travelled in its lifetime (the car’s “mileage”).
  • paint_color: the car’s color.
  • price: the asking price of the car.
  • year: the year the car was bought new.

Read these data into Python as df. Use it to answer the following questions:

import pandas as pd
df = pd.read_csv("toyota-camry-ads.csv")
  1. The ads are from the year 2020. Create a variable in df called age which is the age of the car in years. Cars from 2019 should be 1 year old, cars from 2018 should be 2 years old, and so on.

Answer: The formula linking the variable year and age is age = 2020 - year. We can create this with:

df["age"] = 2020 - df["year"]
  1. Which value of the condition variable is most common?

Answer: One way to see this is to use the value_counts() method:

df["condition"].value_counts()
condition
excellent    728
good         496
like new     143
fair          59
salvage        5
new            3
Name: count, dtype: int64

We can see that excellent has the most values.

Another more direct method is to get the modal value with the mode() method:

df["condition"].mode()
0    excellent
Name: condition, dtype: str

The mode of a vector of values (whether they be numbers or strings) is the most commonly-occurring value.

  1. There are 6 different condition options that can be chosen by the seller to describe the state of the car. Looking at the average odometer and average age by condition, what condition do you think has the highest quality cars on average?

  1. Create a new variable called great_condition that equals True if the condition is excellent, like new or new and is False otherwise.

Answer: One approach would be:

df["great_condition"] = (df["condition"] == "excellent") | \
    (df["condition"] == "like new") | \
    (df["condition"] == "new")

Note that I use \ to split the command across several lines.

A cleaner approach would be:

df["great_condition"] = df["condition"].isin(["excellent", "like new", "new"])
  1. What is the average price of cars that are not in great condition?

Answer:

df[~df["great_condition"]]["price"].mean()
np.float64(5285.2017857142855)
  1. What is the average price of cars that are at least 5 years old that are in great condition?

Answer:

df[(df["age"] >= 5) & df["great_condition"]]["price"].mean()
np.float64(7174.336912751678)
  1. What is the average price of cars that are blue or black?

Answer:

One approach would be:

df[(df["paint_color"] == "blue") | (df["paint_color"] == "black")]["price"].mean()
np.float64(8392.982832618025)

A cleaner approach would be:

df[df["paint_color"].isin(["blue", "black"])]["price"].mean()
np.float64(8392.982832618025)
